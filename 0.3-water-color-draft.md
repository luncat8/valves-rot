# Water colors request

Implement red, green and blue liquid colors that mix. Consider per-color mixability checkboxes; when not mixable red is heavy, green normal and blue light. Provide RGB and darkness views: white RGB becomes black in darkness view, (80,80,80) is fully light, and (255,255,0) is dim.

## input source vents
add water vents on canvas near to top air outputs or above it.
user can 
- slide L/R to choose r,g,b
- slide up/down to choose water source rate from 0 to global settings
- double click to get color picker
- long click to on/off

global column settings cause set parameters of current vent. so if i set red and move global column from 0 to max this cause all set to red liquid. useful to set multiple vents.
