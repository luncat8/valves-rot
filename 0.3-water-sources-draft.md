> ## input source vents
> add water vents on canvas near to top air outputs or above it.
> user can
> - slide L/R to choose r,g,b
> - slide up/down to choose water source rate from 0 to global settings
> - double click to get color picker
> - long click to on/off
>
> global column settings cause set parameters of current vent. so if i set red
> and move global column from 0 to max this cause all set to red liquid.
> useful to set multiple vents.

Slide L/R — sweeps the pour colour around the RGB wheel (one tab width = full revolution; the tab shows the spectrum + a live cursor while dragging)
Slide up/down — sets that vent's rate from 0 to the global Rate ceiling (6000 px²/s, 60px of travel = full range)
Double-click — native colour picker, prefilled with the vent's colour; picks become proportional R/G/B channel shares (black is refused — no ink ratio)
Long-click (~½ s hold) — toggles the vent on/off
Plain click selects a vent as the current one
