# Rotary valve field

Open `index.html` directly in a browser to choose a prototype. No install, build, network access or server is required.

- `prototype/draft.md`: original specification.
- `prototype/comparison.md`: requirements comparison and solver limitations.
- `0.1.1-plan.md`: standalone combined-version design and acceptance gates.
- `pressure-plan.md`: inlet boundaries, air backends, ramp calibration and validation limits.
- `water-plan.md`: phased plan for a water inlet, rising level and buoyancy, with falling droplets deferred.
- `prototype/shared/`: combined implementation. `geometry.js` is the single source of truth for housings, passages, seam apertures and clearance; `simulation.js` advances conserved grains through `sweep` with moving-wall contact and spatial bins; `render.js` strokes those same primitives and batches grains.
- `experiments/`: Node validation and timing scripts (`geometry-check.cjs`, `geometry-fixtures.cjs`, `simulation-fixtures.cjs`, `gas-fixtures.cjs`, `air-fixtures.cjs`, `calibration-fixtures.cjs`, `render-smoke.cjs`, `simulation-bench.cjs`, and `behavior-probe.cjs`).

Click any valve, or focus the canvas and use arrow keys plus Enter/Space (Shift to reverse), to turn a selected valve by 90°. Rotation speed controls valves, not gravity. Static help lives in the **Help** drawer (`?`), which lists every shortcut. The **Place valve** drawer (`V`) is a brush for double-click (or `P` on the selected valve): pick a valve type and/or a direction — each a fixed choice or `?` random, left unselected to keep the current one (click a selected button again to unselect) — copy any field valve's type and direction into the brush, or copy a type name (with the selected direction, when one is selected) to the clipboard as text for chat. Changing only the direction turns the rotor and keeps its grains; changing the type clears that cell.

Air is controlled by the mouths in the two bands: every column has one inlet above the field (low) and one below it (high). Click a mouth to seal or open it, Shift-click to swap its polarity. **Grid gas** (default) shows a relative potential as a blue-to-red overlay and uses it to push grains; a packed pile changes the potential and slows the modeled flow. **Air particles** shows a cyan kinetic population that circulates from bottom sources to top vents and knocks grains about. **Air force** scales the push from 0 (grains behave as with air off) to 2 (updrafts can hold a grain). **Off** leaves the grains untouched. Switching modes does not reset grains or valve targets.

The grid legend displays **equivalent gauge Pa**, not a measured local pressure: it maps the normalized 0–1 field to an editable reference span. The default 0.7125 Pa span comes from a 20-second particle-wall impulse measurement in an idealized reference chamber, using 1 mm/px, 1 s per simulation second, 1 mg per mass unit and 10 mm depth. It does not change the simulation forces, establish atmospheric pressure, or make the grid a thermodynamic model. With every mouth sealed the unanchored overlay is hidden. See `pressure-plan.md` for the assumptions, analytical seam checks and limitations. Run `node experiments/calibration-fixtures.cjs`, `node experiments/gas-fixtures.cjs`, and `node experiments/air-fixtures.cjs` for the checks; `experiments/logs/simulation-pressure.txt` contains earlier coupling and cost measurements.
