# Vanilla prototype migration

## Review

The initial repository had two React/TypeScript/Vite implementations and one standalone HTML geometry study. No earlier implementation log was present. The runtime contradicted the project guide; the GLM Max elbow used an origin-centered arc with nontangent radial joins.

## Changes

- Converted both engines to readable classic JavaScript namespaces with guarded Node exports; removed framework entry points, TypeScript, configs, dependency manifests and lockfiles.
- Added standalone HTML controls and shared local CSS, a root gallery and usage documentation. The converted toolbar is intentionally simpler than the framework layouts. GPT retains pointer/keyboard rotation.
- Corrected GLM elbow curvature using an offset arc center with tangent legs. Drawing, air tests and arc seeding use the same center and angular sector.
- Reused GLM escape-query scratch buffers instead of allocating candidates/results during collision recovery. Corrected rotation-speed scaling of wall velocity in the vanilla loop.
- Compared all three sources with the draft and separated the combined-version design from this implementation record.

## Validation

- All converted JavaScript files passed `node --check`.
- `node experiments/geometry-check.cjs` passed: 30 random layouts, 245 sampled elbows, tangent joins, midpoint air on the intended side and blocked on the opposite side, finite particle state and population smoke checks; both engines load under Node.
- Tests stub Path2D and do not validate canvas rendering. No browser visual/file-protocol verification was performed. Full conservation and realistic granular flow remain future acceptance criteria, not claims of this port.

Implement deterministic shared geometry fixtures and seam/contact handling from `0.1.1-plan.md`, then verify both standalone pages visually in a browser before tuning physics.
