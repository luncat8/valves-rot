Node v22.22.3, Intel Xeon 2.60 GHz, 2 cpus, uncontended passes

Deleted from the display projection: the face/apR/apD/comp/open/fill/cond mirrors,
the extra conductance syncs that only existed to keep them warm, the duplicated
edge build and a redundant measure pass. The rebuild is gated on the dirty flag
the network already carried. Every row the solver itself produces is identical
between the two trees (simulation-bench, gas-fixtures, front-probe, and the
combined-solver rows of behavior-probe; only that probe's glm reference rows
jitter, run to run, in both trees), so every number below is a cost change and
not a behaviour change.
